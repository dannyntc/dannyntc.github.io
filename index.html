03 · Curiosity

The Workbench

Software tools, automation experiments, and small attempts to make a task less awkward.

Tool

TranscribeBuddy

formerly Faster-Whisper Command Builder

A small interface for composing local transcription commands without remembering every flag.

Problem, process, and reflection

The problem: Multi-step command-line tools are useful but easy to misremember.

The idea: Turn the command into a set of readable choices that can produce a repeatable invocation.

The tools: Faster-Whisper command workflows and a lightweight interface.

The reflection: A small amount of structure can make a private, local workflow much easier to return to.

Tool

VideoBuddy

formerly Video Converter & Subtitle Embedder

A repeatable way to compose commands for converting videos and embedding subtitles.

Problem, process, and reflection

The problem: Video utilities can feel heavier than the task itself.

The idea: Put the common command options into a clearer, lighter workflow.

The tools: Video conversion and subtitle-embedding command workflows.

The reflection: A tool is useful when it removes the memory burden without hiding what is actually happening.

View the repository ↗
System

AI-powered Job Search System

Opportunity evaluation and application tracking

A customised end-to-end system for evaluating roles against defined skills and interests, then keeping applications organised.

Problem, process, and reflection

The problem: A job search can create repetitive evaluation and administration before the important judgment begins.

The idea: Use an agentic workflow to prioritise high-fit opportunities over applying at volume.

The tools: Claude Code, structured task delegation, layered validation, and deterministic HTML/CSS document rendering.

The reflection: Automation is most useful here when it protects attention for deciding which opportunities deserve it.

Workflow

AI-powered Sample Work Generator

Evidence-led application documents

A workflow for turning a job description and application materials into a concise cover letter and independent proof of work.

Problem, process, and reflection

The problem: A conventional application often leaves useful evidence scattered across separate documents.

The idea: Combine the application narrative with a tailored work sample and check the final layout before use.

The tools: AI-assisted drafting, HTML/CSS rendering, and visual review.

The reflection: The strongest output is not the one with the most automation; it is the one that makes the evidence easier to judge.
