Layers between 04 and 05

04A
Generated pseudo-element box content: "" and height: 13px; this is the box that carries the separator treatment.
04B
Transparent pass-through surface background: transparent; the box itself does not paint an opaque paper band.
04C
Negative placement offset bottom: -13px; positions the generated box immediately below the header boundary.
04D
Shadow paint / visual separator box-shadow: 0 6px 12px rgba(...); the offset and blur create the visible soft strip.
04E
Header paper surface and box edge .site-header supplies background: var(--paper); its border-box edge is the protected stacking boundary.

What happens during the scroll

The transition is a stacking and geometry behavior, not a JavaScript animation.

  1. 1 · Before the boundary .intro-label is fully visible below the normal header flow.
  2. 2 · Crossing the boundary The label’s box moves upward into the sticky header’s bottom area and becomes partially occluded.
  3. 3 · Covered state The header background and stacking order cover the label; only the header shadow remains visible at the separator.

In the live page, the transition is controlled by position: sticky, top: 0, the mobile padding-bottom: 10px, the ::after shadow, and z-index: 10 on .site-header.
